# 検証ガイドライン

> このファイルは以下の情報の **Truth Source** です：
> - 動作検証の基準と手順
> - ブラウザテスト要件
> - デプロイ前チェック項目

## 基本原則

1. **ブラウザで実際に動作確認する**: TypeScriptの型チェックだけでなく、実際のブラウザで検証する
2. **複数の画像形式でテストする**: JPEG, PNG, WebP それぞれで背景除去を確認する
3. **タッチ操作を検証する**: DevToolsのデバイスモードでタッチ操作を確認する

## 検証基準

### レベル1: 必須検証

| 対象 | 検証方法 | 判定基準 |
|------|---------|---------|
| 画像アップロード（クリック） | ファイル選択で画像を読み込む | プレビューに遷移する |
| 画像アップロード（D&D） | 画像をドラッグ&ドロップ | プレビューに遷移する |
| 背景除去 | 各形式の画像で実行 | 背景が除去され合成画像が表示される |
| プログレス表示 | 処理中に画面を確認 | 「背景を除去中...」と表示される |
| 被写体ドラッグ | マウス/タッチでドラッグ | 位置が移動する |
| スケールスライダー | スライダーを操作 | 被写体のサイズが変わる |
| 回転スライダー | スライダーを操作 | 被写体が回転する |
| 背景切替（銀河） | 銀河サムネイルをタップ | 背景が渦巻銀河に変わる |
| 背景切替（星雲） | 星雲サムネイルをタップ | 背景がカラフルな星雲に変わる |
| 背景切替（深宇宙） | 深宇宙サムネイルをタップ | 背景が暗い星空に変わる |
| 背景切替（惑星） | 惑星サムネイルをタップ | 背景が惑星近景に変わる |
| 背景切替後の被写体 | 背景切替後に被写体を確認 | 位置・サイズが維持されている |
| 反転ボタン | ↔ 反転 をクリック | 被写体が左右反転する |
| 保存ボタン | 💾 保存 をクリック | PNGファイルがダウンロードされる |
| リセットボタン | 🔄 リセット → 確認ダイアログ | アップロード画面に戻る |
| ビルド | `pnpm build` | エラーなし |
| プライバシー | DevTools Network タブ | 画像データの外部送信なし |

### レベル2: 推奨検証

| 対象 | 検証方法 | 判定基準 |
|------|---------|---------|
| ピンチ操作 | DevToolsデバイスモードまたは実機 | 2本指でズーム+回転 |
| Web Share API | モバイル実機でシェアボタン | OS共有シートが表示される |
| Xポストボタン | ポストボタンをクリック | x.com/intent/post が開く |
| クリップボードコピー | デスクトップでシェアボタン | 画像がコピーされトースト表示 |
| ハッシュタグコピー | #SpaceCat テキストをタップ | コピー確認トースト表示 |
| 大画像（5MB超） | 高解像度画像でアップロード | リサイズフォールバック動作 |
| メモリ不足時 | 大画像+低スペック環境 | 「メモリ不足」メッセージ表示 |
| 背景画像フォールバック | WebP非対応環境 | bg.png にフォールバック |
| サンプル画像表示 | 初期画面を確認 | sample.webp/png が表示される |
| OGPプレビュー | SNSシェアプレビュー | タイトル・説明・画像が正しい |

### レベル3: 注意喚起

| 対象 | 対応方法 |
|------|---------|
| 低スペック端末 | メモリフォールバック(1024→768→512px)が動作するか |
| ネットワーク切断 | ONNXモデル未ダウンロード時のエラーメッセージ |
| Safari固有の挙動 | canvas.toBlob()、Web Share API の互換性 |

## 検証フロー

### Step 1: ローカル動作確認

```
□ pnpm dev で開発サーバーが起動するか
□ 画像をクリック選択で読み込めるか
□ 画像をドラッグ&ドロップで読み込めるか
□ 「背景を除去中...」と表示されるか
□ 背景除去後に合成画像がCanvasに表示されるか
□ ドラッグガイドが3秒間表示されるか
□ 被写体のドラッグ移動が動作するか
□ サイズスライダー・回転スライダーが動作するか
□ ↔ 反転ボタンが動作するか
□ 💾 保存でPNGダウンロードされるか
□ 🔄 リセットで初期画面に戻るか
```

### Step 2: ビルド・デプロイ確認

```
□ pnpm build がエラーなしで完了するか
□ pnpm preview でビルド結果が正しく表示されるか
□ 背景画像(bg.webp/png)がビルド後も正しく表示されるか
□ サンプル画像(sample.webp/png)が表示されるか
□ GitHub Pagesのbase設定が正しいか
```

### Step 3: プライバシー・セキュリティ確認

```
□ DevToolsのNetworkタブで画像データの外部送信がないか
□ 画像処理がすべてクライアントサイドで完結しているか
□ コンソールにシークレット情報が出力されていないか
□ .envファイルがgitignoreに含まれているか
```

## 問題検出時の対応

### 深刻度の判定基準

| 深刻度 | 基準 | 対応 |
|--------|------|------|
| 高 | 背景除去が動作しない、画像が外部送信される、ビルド失敗 | 即時修正 |
| 中 | 特定形式で動作しない、タッチ操作の不具合、シェア機能の不具合 | 可能な限り修正 |
| 低 | アニメーション、レイアウト微調整 | 次回以降で対応 |
