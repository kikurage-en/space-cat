# 設定ファイル改善・フィードバック生成スキル

運用中に発見した改善点を構造化し、claudewizardへのフィードバックを準備する。

## 目的

- 設定ファイルの自己検証
- 改善点の構造化
- claudewizardへのフィードバック準備

## 実行フロー

### Step 0: フィードバックファイル存在チェック

```bash
ls *-feedback.md 2>/dev/null
```

**ファイルが存在しない場合**: Step 1に進む（新規作成モード）
**ファイルが存在する場合**: 既存ファイルを読み込み、ステータスを確認

### Step 1: 設定ファイルの現状分析

対象ファイル:
- CLAUDE.md
- .claude/rules/
- .claude/references/
- .claude/skills/

以下を確認:
- 各ファイルの構造
- @参照の整合性
- 追加・変更されたセクション

### Step 2: 問題の文脈収集

ユーザーに以下を質問:
1. どんな作業をしていたときに問題が発生しましたか？
2. 具体的に何が起きましたか？
3. その結果、どうなりましたか？
4. どのように解決しましたか？
5. その解決策は他のプロジェクトでも役立ちそうですか？

### Step 3: コミット履歴の自動分析

```bash
git log --oneline -- CLAUDE.md .claude/
git diff [初期コミット]..HEAD -- CLAUDE.md .claude/
```

### Step 4: 改善提案の構造化

収集した情報を以下の形式で整理:

| 分類 | 問題の概要 | 解決策 | 汎用性 | 優先度 |
|------|-----------|--------|--------|--------|
| 追加 | [何が困ったか] | [何を追加したか] | 高/中/低 | 高/中/低 |

### Step 5: フィードバックファイル生成

`inspiration-cat-feedback.md` を生成する。
